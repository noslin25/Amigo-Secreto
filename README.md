Amigo Secreto

O projeto **Amigo Secreto** é uma aplicação que facilita a organização de sorteios de amigo secreto, permitindo que os participantes se inscrevam, sejam sorteados e recebam notificações sobre quem devem presentear.

## Funcionalidades

- **Cadastro de Participantes**: Permite que os usuários se inscrevam para participar do sorteio.
- **Sorteio Automático**: Realiza o sorteio de forma aleatória, garantindo que cada participante tenha um amigo secreto.
- **Notificações**: Envia notificações por e-mail para os participantes informando quem eles devem presentear.
- **Interface Amigável**: Uma interface simples e intuitiva para facilitar a interação dos usuários.
